# Traces

Store non-trivial agent run logs here.

Use this filename format:

```text
YYYY-MM-DD_HHMM_task-name.md
```

Use the template below:

```markdown
---
timestamp:
task:
provider:
model:
profile:
status: completed | partial | blocked
---

# Task

# Files Read

# Files Changed

# Tools Used

# Key Decisions

# Uncertain Claims

# Next Actions
```
